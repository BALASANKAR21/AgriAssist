# **App Name**: AgriAssist

## Core Features:

- Voice-Enabled Dashboard: A dashboard with voice commands for easy navigation and information retrieval.
- Community Pest Alert: A map-based feature using react-leaflet where farmers can report pest attacks, creating a visualized warning zone for neighbors.
- Voice Ledger: Expense tracker where farmers can log expenses via voice input.
- Offline Access: Progressive Web App (PWA) functionality ensuring the app works offline using service workers.
- Text-to-Speech Updates: The application is able to use Text-to-Speech functionality to inform users of different status updates and values.
- AI-Powered Insights Tool: AI tool provides customized, actionable, agriculture related recommendations based on expenses in the ledger. The AI tool will reason to decide when to provide those recommendations, or provide extra, helpful, contextual details related to a specific agricultural topic. The AI tool will act as a tool.

## Style Guidelines:

- Primary color: Earthy green (#388E3C) to reflect agriculture and nature.
- Secondary color: Saffron hint (#FFB300) for key accents and highlights.
- Background color: Cream (#FFFDD0), providing a gentle backdrop for content.
- Accent color: Warm orange (#FF7043) for call-to-action buttons and important alerts, especially the Pest Alert widget.
- Body and headline font: 'PT Sans', a humanist sans-serif, to ensure readability and accessibility for users with varying levels of digital literacy.
- Use large, simple icons from Lucide-React that are visually intuitive and require minimal text.
- Mobile-first, bento grid layout with large, touch-friendly cards for easy navigation on small screens.
- Subtle animations and transitions to provide feedback on user interactions without being distracting.
